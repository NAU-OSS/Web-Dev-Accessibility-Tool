# Web-Dev-Accessibility-Tool
[This is a sample repository for CS499 with no plans to be completed or actively maintained. If you are looking for web accessibility audit tools, I recommend referring to this list: https://www.w3.org/WAI/test-evaluate/tools/list/.]

A developer tool that scans local HTML, CSS, and JavaScript code to identify accessibility barriers, and offers suggestions for reorganization and palette recoloring.
